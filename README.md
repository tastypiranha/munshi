# Munshi

Speak your problem in any Indian language. Munshi detects the language, writes a formal letter in the language you choose, and reads it aloud so you can verify it before sending.

Built with Next.js and Sarvam AI (speech-to-text, chat, translation, text-to-speech).

## Run locally
```bash
npm install
echo "SARVAM_API_KEY=your_key" > .env.local
npm run dev
```
Open http://localhost:3000
